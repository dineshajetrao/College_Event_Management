# College Event Management

## Objective
A small system to manage college events: student registration, event management, login and reports. Built to practise a DevOps workflow (Plan, Code, Commit, Push, Review, Build/Test, Deploy) using GitHub.

## Technologies Used
Node.js, Jest, HTML, Git, GitHub, GitHub Actions, GitHub Pages

## Installation
1. Clone the repository: `git clone https://github.com/YOUR-USERNAME/college-event-management.git`
2. Go into the folder: `cd college-event-management`
3. Install dependencies: `npm install`
4. Run tests: `npm test`
5. Build the project: `npm run build`
